# Open BIM & Interoperability Specification

ArchAI Studio v3 compiles canonical building entities into standard Open BIM formats:

| Format | Standard | Target Application |
|---|---|---|
| **IFC4** | buildingSMART IFC4_ADD2_TC1 | Revit, ArchiCAD, Solibri, BlenderBIM |
| **DXF** | AutoCAD R12 / 2000 ASCII | AutoCAD, LibreCAD, CNC blueprinters |
| **glTF / GLB** | Khronos Group glTF 2.0 | Three.js, WebGL, Unreal Engine |
| **Speckle** | Speckle 2.0 Stream Object Model | Rhino, Grasshopper, Revit Cloud |
| **APS SVF** | Autodesk Platform Services SVF2 | Autodesk Viewer, ACC, BIM 360 |
